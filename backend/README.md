# Backend

API en FastAPI que concentra la lógica de negocio, la autenticación, la autorización y el acceso a datos (PostgreSQL con SQLAlchemy y Alembic). Incluirá los módulos del monolito, los adaptadores (gateways) de las fuentes de anuncios, las migraciones y las pruebas con Pytest.

Pendiente de crear en la fase de base técnica.
